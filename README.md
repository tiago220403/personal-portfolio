# Portfólio pessoal

Portfólio com minha experiência profissional, formação em Ciências da
Computação e canais de contato.

**[Acessar o portfólio](https://tiago-portella-portfolio.vercel.app/)**

## Destaques

- Animações que acompanham a rolagem com GSAP e ScrollTrigger.
- Iluminação sutil que segue o cursor e reage à passagem do mouse.
- Layout responsivo que respeita a preferência por movimento reduzido.

## Tecnologias

HTML, CSS, JavaScript e GSAP. Hospedado na Vercel.
